# Snake Game using ncurses
Gioco Snake classico sviluppato in C++ per Terminale

## Funzionalità
* Struttura a Livelli con progressivo aumento della velocità e tempo limite
* Lunghezza fissa del Serpente
* Timer realizzato con libreria Chrono
* Grafica ASCII
* Menù di Pausa Iniziale
* Matrice Booleana come griglia di gioco
* File per Classifica con funzioni di scrittura e lettura

## Comandi di Gioco
- **Frecce Direzionali**: Movimento
- **ESC**: Pausa
- **N / P**: Cambia Livello (in gioco)
- **INVIO**: Selezione nel Menu

## Compilare
```bash 
make ./Snake
